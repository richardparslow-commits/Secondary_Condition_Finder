## What this does

Working branch for VA claim-prep research tooling. On top of the branch's
original "citations ship unverified" invariant work, it now carries:

- **100-case PTSD → ED consistency harness** (`tests/ptsd-ed-process.test.ts`):
  proves the engine renders the same erectile-dysfunction opinion for
  service-connected PTSD across determinism, input variants, exclusions,
  merges, workflow integration, and file evaluation.
- **Catalog ↔ KB alignment:** 193 catalog conditions ↔ 193 published
  mappings, one-to-one and test-enforced. Adds the unhyphenated
  "post traumatic stress disorder" alias so it resolves to PTSD.
- **Authoring backlog:** `draft-backlog-tracker.csv` is generated from the
  catalog (`UNMAPPED`/`DRAFT` statuses) and is empty because every mapping
  is published. `docs/kb-coverage-tracker.md` reflects that.
- **Build/lint fixes:** `next.config.mjs` was silently shadowing
  `next.config.ts` (Turbopack root pin, data tracing, better-sqlite3
  external); merged into the `.ts` config and deleted. Lint is clean:
  the nested `Secondary_Condition_Finder/` clone is ignored by ESLint,
  unescaped entities and unused vars fixed (CI runs `npm run lint`).
- **Exposure discoverability (P1 gate):** `exposure-tags.ts` ids corrected
  to real catalog entries (`lymphoma` → hodgkins/non-hodgkins-lymphoma,
  `melanoma` → skin-cancer), wired as a "toxic exposure related" badge on
  `/secondary/diagnosed`, with catalog-consistency and route tests.
- **Dead code removed:** `src/lib/presumptive/pactAct.ts` (unused, with
  phantom condition ids and lowercase locations that could never match the
  shipped burn-pit data).
