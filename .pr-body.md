## What this does

Brings this branch's test suite to green (109 tests passing, typecheck clean,
production build OK) by restoring the repo's "citations ship unverified"
invariant:

- **Citations:** every `data/knowledge-base` reference is `verified: false`
  again, and the schemas reject `verified: true` unless a human confirms it.
  The catalog and KB source-reference schemas are locked to `literal(false)`;
  the presumptive schema keeps an explicit `.refine` guard with a
  "Source references cannot be marked verified without human review" message
  on the `verified` path.
- **Catalog ↔ KB alignment:** catalog and knowledge base are reconciled 1:1
  (193 ids each). Adds the conditions mappings depend on
  (`diabetes-mellitus-type-2`, `migraine-headaches`, ALS, cerebral palsy, the
  radiculopathy family, thyroid/Cushing's/type-1 diabetes) and consolidates
  five mapping filenames to their canonical catalog ids.
- **UI:** restores the `HomePage` default export that a component refactor had
  clobbered, and adds the ratings "I prefer not to answer" decline option.
- **Regression guard:** a new test asserts the catalog id set and the published
  mapping id set are identical, so id drift fails fast.
- **Housekeeping:** nested clone excluded from git and TypeScript,
  `turbopack.root` pinned, lockfile ranges synced, README note on the cosmetic
  Turbopack workspace-root warning.
