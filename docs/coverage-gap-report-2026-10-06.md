## What is measured

`docs/mapping-coverage.md` reports how much of the catalog is mapped. This report covers the
opposite face: the identities that carry **no** authored suggestion of their own, so the
repository can learn nothing from them, and asks which of them the repository is already
pointing at.

| Column | Definition |
| --- | --- |
| `requestedAsSecondary` | Times the identity is named as the **secondary** condition in an authored CRG request row under `docs/` (95 rows across 20 packet files). Recorded demand, measured outside the knowledge base it informs. |
| `inboundEdges` | Authored relationships in `data/knowledge-base/*.json` that already name the identity as a secondary. Existing coverage. |
| `graphInboundEdges` | The same count restricted to the adjacency store `data/knowledge-base/graph/`, which currently holds 7 nodes. |
| `gapScore` | `(1 + requestedAsSecondary) / (1 + inboundEdges)` — demand carried against coverage already present. Rows are ordered by it, then by recorded demand, then by id. |

## Limitations

- Demand is recorded demand only. It is read from 20 authored CRG request packets in `docs/`; this repository holds no field data on how often a secondary claim actually arises in claims processing, so `requestedAsSecondary` measures what reviewers asked for, not what claimants file.
- **5** request rows name a secondary condition that does not resolve to a catalog identity (descriptive phrases such as "Posterior subcapsular cataract (corticosteroid-induced)"). Those rows contribute no demand to any identity, so demand is undercounted; the full list is in the JSON companion under `unresolvedRequestNames`.
- `inboundEdges` counts edges whose host file may itself still be `draft: true`. An inbound edge is coverage of the target only in the sense that some primary already proposes it.
- A blank identity is not a defect on its own: several carry `todo` notes recording that evidence was sought and no compatible downstream condition was found. This report ranks where to look next; it does not assert that every blank identity has mappings to author.
